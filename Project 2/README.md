## 📖 Overview
This project systematically evaluates the reasoning capabilities of Large Language Models (LLMs), specifically GPT-4.1, over structured Knowledge Graphs (KGs). The primary objective is to assess how well an LLM can deduce single-hop, multi-hop, and non-hierarchical relationships across diverse domains. It compares the model's zero-shot reasoning abilities against context-augmented prompting where explicit graph data is provided.

## ✨ Key Features
*   **Diverse Knowledge Graphs:** Utilizes four distinct ontologies to ensure robust evaluation: **CSO** (Computer Science), **FMA** (Biology), **Pleiades** (Geography), and **RxNorm** (Medicine).
*   **Systematic Triplet Extraction:** Automatically extracts `(Subject, Predicate, Object)` triplets, categorizing them into hierarchical (`is_a`) and non-hierarchical (`other`) relationships.
*   **Multi-Level Question Generation:** Generates balanced YES/NO questions across three difficulty levels: Single-hop (direct `is_a`), Multi-hop/Long-chain (paths of 4-7 hops), and Non-taxonomic relations.
*   **Prompting Strategy Analysis:** Compares "Conventional Prompts" (relying on the LLM's internal knowledge) vs. "Full Data Prompts" (injecting the KG triplets into the prompt), revealing a performance jump from ~50% (random guess) to ~100% accuracy.

## 🏗️ Repository Structure
The repository is systematically organized to separate raw data, prompts, questions, and model responses:
*   📄 `main.ipynb`: The core Jupyter Notebook containing the data extraction, processing, and evaluation logic.
*   📁 `cleaned_isa/`: Extracted CSV files containing hierarchical (`is_a`) relations for each ontology.
*   📁 `prompt_csvs/`: Formatted CSV files specifically designed to be passed as prompts to the LLMs.
*   📁 `questions/`: The generated YES/NO questions, split into `isa/` (single-hop), `isa_long/` (multi-hop), and `other/` categories.
*   📁 `responses/gpt 4.1/`: The raw outputs and answers generated by the GPT-4.1 model for both Conventional and Full Data prompts.

## 📊 Usage & Deployment
To explore and replicate this evaluation pipeline:
1.  **Environment Setup:** Ensure you have a Python environment with Jupyter Notebook and Pandas installed to run `main.ipynb`.
2.  **Examine the Data:** Check the `cleaned_isa/` folder to see the structured `(Subject, Predicate, Object)` triplets extracted from the raw KGs.
3.  **Review the Questions:** Open the `questions/` directory to view the systematically generated YES/NO questions for different reasoning depths.
4.  **Analyze LLM Performance:** Compare the CSV files in `responses/gpt 4.1/Is_a/Conventional Prompt/` versus `responses/gpt 4.1/Is_a/Full Data/` to observe the stark difference in accuracy when the model is provided with explicit graph context.
